Coming soon · Underpainting

See the foundation
before you paint it.

Underpainting is already taking shape as a focused analysis studio. These real screens show how it simplifies a reference, reveals its values, and helps artists plan the first painted layer.

01

Preview a real underpainting

Convert a reference into a simplified warm underpainting study with adjustable tones and value levels.

02

Find values directly in the image

Sample any point and identify its position on a clear ten-step value scale.

03

Compare every simplification level

Review the original, posterized study, and multiple value reductions side by side.

04

Isolate the shapes you need to paint

Show individual value groups and block-in colors to understand the large structure first.

Coming soon · Painterra Studio

See color as a
living structure.

Painterra Studio turns the Munsell color system into an interactive workspace. These real screens show hue, value, and chroma in multiple views and connect selected colors to practical paint matches.

01

Explore color as a 3D solid

Rotate, zoom, and inspect how hue, value, and chroma relate across the complete color structure.

02

Study one hue family in detail

Move through value and chroma in a clear flat view and select an exact Munsell color position.

03

Compare the full family of hues

See every major hue page together to understand how value and chroma shapes change around the color space.

04

Connect color theory to real paint

Compare chart colors with the nearest available paint matches in a practical, studio-ready report.

In development · Drawtrezzi

Plan it. Compose it.
Draw it. Paint it.

Drawtrezzi is a drawing, painting, and composition studio built specifically for artists. It brings references, professional visual guides, drawing tools, painting tools, and layers together on one canvas.

01

Draw and paint in one artist-first studio

Move from the first graphite sketch to painted color using pencils, pens, brushes, layers, and adjustable canvas tools.

02

Build complete compositions from references

Import multiple images, remove backgrounds, reposition elements, add text, and arrange the scene before committing it to canvas.

03

Use professional guides directly on the canvas

Work with movable rulers, grids, horizon lines, perspective tools, Rule of Thirds, and Golden Ratio guides while you draw.

04

Keep every drawing decision within reach

Control rulers, markers, layers, brush behavior, color, opacity, and composition without leaving the creative workspace.

About Arttrezzi

Digital tools for traditional artists.

Arttrezzi is a professional artist toolbox designed for painters, illustrators, and visual artists. It helps artists plan compositions, measure layouts, match colors, study values, and prepare artwork for printing.

Our goal is simple: let technology handle the preparation so artists can spend more time making art.
