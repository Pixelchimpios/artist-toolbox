# Arttrezzi website — GitHub Pages

These files replace a basic GitHub Pages website.

1. Open your GitHub repository for `arttrezzi.com`.
2. Upload or replace `index.html` and add `privacy.html` in the repository root.
3. Commit the changes.
4. In GitHub, go to **Settings → Pages** and confirm the site publishes from the root of the main branch.
5. Keep your existing custom-domain setting for `arttrezzi.com` enabled. Do not remove the `CNAME` file if your repository already has one.

The home page identifies **Maximino LLC** as the legal company and **Arttrezzi** as its software brand, gives the Apple-required domain email, and includes substantive app information.
